# arc/tube — the narrative tube

The arc thickened into a tube: a polygon cross-section at every window, swept
along the fitted 3-D curve with rotation-minimizing frames, so the shape changes
over reading time. `--section emotions` puts one vertex per emotion (the tube
bulges toward whichever is strong); `--section spread` uses the window's own
paragraph scatter. `tube_explorer.py` is the interactive version, with
thickness, smoothing and rounding as live controls.

    python tube/arc_tube.py                            # run from arc/
    python tube/arc_tube.py --section spread --sides 16
    python tube/tube_explorer.py

Construction and options: [../README.md](../README.md#narrative-tube).
